Android / iPhone / iPad

  1. App „WireGuard“ aus dem Play Store bzw. App Store installieren.
  2. In der App auf + tippen → „QR-Code scannen“{% if not wg_qr %} (QR-Code in der Weboberfläche des Servers) oder „Aus Datei importieren“ und die unten geladene Datei wählen{% endif %}.

Windows / macOS

  1. WireGuard von wireguard.com/install bzw. aus dem Mac App Store installieren.
  2. „Tunnel aus Datei importieren“ und die Konfigurationsdatei wählen → Aktivieren.

Linux

Datei nach /etc/wireguard/wg-vpn.conf kopieren und sudo wg-quick up wg-vpn ausführen – oder in NetworkManager importieren: nmcli connection import type wireguard file wg-vpn.conf

{% endif %} {# ================= OpenVPN ================= #} {% if enabled(state, 'openvpn') %}

Bewährtes, sehr kompatibles VPN. Das Profil enthält alle Zertifikate{% if state.proto.openvpn.udp and state.proto.openvpn.tcp %} und versucht zuerst UDP, dann TCP (funktioniert auch in restriktiven Netzen){% endif %}.

OpenVPN-Profil (.ovpn)

Android / iPhone / iPad

  1. App „OpenVPN Connect“ installieren (Android alternativ: „OpenVPN for Android“).
  2. Die .ovpn-Datei öffnen bzw. in der App unter „Profil importieren → Datei“ auswählen.
  3. Verbindung antippen.

Windows / macOS

  1. OpenVPN Connect (openvpn.net) oder unter Windows OpenVPN GUI, unter macOS alternativ Tunnelblick installieren.
  2. Profil importieren (Doppelklick bzw. „Import Profile“) und verbinden.

Linux

sudo openvpn --config {{ c.name }}.ovpn oder nmcli connection import type openvpn file {{ c.name }}.ovpn

{% endif %} {# ================= IKEv2 ================= #} {% if enabled(state, 'ikev2') %}

IKEv2/IPsec ist in Android, iOS, macOS und Windows ohne zusätzliche App eingebaut. Drei Anmeldearten stehen zur Wahl: Zertifikat (am sichersten), Pre-Shared Key (am einfachsten) oder Benutzername/Passwort.

Android 11 oder neuer. Einstellungen → Netzwerk & Internet → VPN → + (je nach Hersteller z. B. „Verbindungen → Weitere Verbindungseinstellungen → VPN“).

Variante „IKEv2/IPSec PSK“ (Pre-Shared Key)

Neues VPN-Profil anlegen und folgende Werte eintragen:

{{ kv('Typ', 'IKEv2/IPSec PSK', False) }} {{ kv('Serveradresse', host) }} {{ kv('IPSec-ID', c.psk_id) }} {{ kv('Vorinstallierter IPSec-Schlüssel', c.psk) }}

Variante „IKEv2/IPSec RSA“ (Zertifikat)

  1. CA-Zertifikat herunterladen. Einstellungen → Sicherheit → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat → Datei vpn-server-ca.crt wählen.
  2. Client-Zertifikat (.p12) herunterladen. Zertifikat installieren → VPN- und App-Nutzerzertifikat → Datei wählen, Passwort: {{ c.p12_password }}
  3. VPN-Profil anlegen:
    {{ kv('Typ', 'IKEv2/IPSec RSA', False) }} {{ kv('Serveradresse', host) }} {{ kv('IPSec-ID', c.name) }} {{ kv('IPSec-Nutzerzertifikat', c.name ~ ' (' ~ (state.server.name or 'VPN-Server') ~ ')', False) }} {{ kv('IPSec-CA-Zertifikat', info.ca_cn, False) }} {{ kv('IPSec-Serverzertifikat', 'Vom Server empfangen', False) }}

Variante „IKEv2/IPSec MSCHAPv2“ (Benutzername/Passwort)

  1. CA-Zertifikat wie bei der RSA-Variante als CA-Zertifikat installieren.
  2. VPN-Profil anlegen:
    {{ kv('Typ', 'IKEv2/IPSec MSCHAPv2', False) }} {{ kv('Serveradresse', host) }} {{ kv('IPSec-ID', c.name) }} {{ kv('IPSec-CA-Zertifikat', info.ca_cn, False) }} {{ kv('IPSec-Serverzertifikat', 'Vom Server empfangen', False) }} {{ kv('Nutzername', c.name) }} {{ kv('Passwort', c.password) }}

Automatisch per Profil (empfohlen)

  1. Profil auf dem Gerät öffnen (am einfachsten über den Teilen-Link in Safari):
    Profil mit Zertifikat Profil mit Benutzername/Passwort
  2. iPhone/iPad: Einstellungen → Profil geladen → Installieren (Gerätecode eingeben). Mac: Doppelklick, dann Systemeinstellungen → Datenschutz & Sicherheit → Profile → Installieren.
  3. Einstellungen → VPN → „{{ state.server.name or 'VPN-Server' }}“ einschalten.

Manuell mit Pre-Shared Key

Einstellungen → Allgemein → VPN & Geräteverwaltung → VPN → VPN hinzufügen:

{{ kv('Typ', 'IKEv2', False) }} {{ kv('Server', host) }} {{ kv('Entfernte ID', host) }} {{ kv('Lokale ID', c.psk_id) }} {{ kv('Benutzerauthentifizierung', 'Keine', False) }} {{ kv('Zertifikat verwenden', 'aus', False) }} {{ kv('Geheimer Schlüssel', c.psk) }}

Laden Sie ein Einrichtungsskript herunter und starten Sie es mit Rechtsklick → „Als Administrator ausführen“. Es importiert das CA-Zertifikat und legt die VPN-Verbindung mit sicheren Verschlüsselungseinstellungen an.

Skript: Benutzername/Passwort Skript: Zertifikat

Danach: Einstellungen → Netzwerk und Internet → VPN → „{{ state.server.name or 'VPN-Server' }} IKEv2“ → Verbinden. Bei der Passwort-Variante Benutzername {{ c.name }} und Passwort {{ c.password }} eingeben.

Windows SmartScreen kann vor heruntergeladenen Skripten warnen („Weitere Informationen → Trotzdem ausführen“). Sie können den Inhalt vorher mit einem Texteditor prüfen.

Die kostenlose App „strongSwan VPN Client“ (Android) unterstützt alle Varianten und importiert das fertige Profil inklusive Zertifikaten.

Profil mit Zertifikat (.sswan) Profil mit Passwort (.sswan)

App öffnen → Menü → „VPN-Profile importieren“ → Datei wählen. Beim Zertifikatsprofil das Passwort {{ c.p12_password }} eingeben, beim Passwortprofil beim Verbinden {{ c.password }}.

NetworkManager mit Plugin network-manager-strongswan installieren. Neue VPN-Verbindung „IPsec/IKEv2 (strongswan)“:

{{ kv('Server/Adresse', host) }} {{ kv('Server-Identität', host) }} {{ kv('Zertifikat (CA)', 'vpn-server-ca.crt', False) }} {{ kv('Authentifizierung', 'EAP (Benutzername/Passwort) oder Zertifikat (.p12)', False) }} {{ kv('Benutzername', c.name) }} {{ kv('Passwort', c.password) }}

„Innere IP-Adresse anfordern“ aktivieren.

Älteres, aber weit verbreitetes Protokoll – eingebaut in Windows, macOS, iOS und Android bis Version 11. Für neue Installationen sind WireGuard oder IKEv2 besser.

{{ kv('Server', host) }} {{ kv('IPsec-Pre-Shared-Key', info.psk) }} {{ kv('Benutzername', c.name) }} {{ kv('Passwort', c.password) }}

Windows

Einrichtungsskript mit Rechtsklick → „Als Administrator ausführen“. Das Skript setzt außerdem den für Server hinter NAT nötigen Registry-Eintrag (AssumeUDPEncapsulationContextOnSendRule = 2) – danach Windows neu starten.

iPhone / iPad / Mac

VPN hinzufügen → Typ L2TP → Server, Account (Benutzername), Passwort und „Shared Secret“ (PSK) eintragen, „Gesamten Verkehr senden“ aktivieren.

Android bis Version 11

Typ „L2TP/IPSec PSK“, Serveradresse, „Vorinstallierter IPSec-Schlüssel“ = PSK; L2TP-Schlüssel und IPSec-ID leer lassen.

Linux

Plugin network-manager-l2tp installieren, unter „IPsec-Einstellungen“ den PSK eintragen.

Android

App „Open SSTP Client“ (Play Store/F-Droid): Hostname {{ host }}, Port {{ state.proto.sstp.port }}, Benutzername und Passwort.{% if not info.le %} Unter „Zertifikat“ das CA-Zertifikat angeben oder „Zertifikat nicht prüfen“ wählen.{% endif %}

Plugin network-manager-sstp oder sstpc --ca-cert vpn-server-ca.crt --user {{ c.name }} --password … {{ info.sstp_addr }} usepeerdns require-mschap-v2 noauth

macOS und iOS haben keinen eingebauten SSTP-Client – dort besser IKEv2 oder WireGuard verwenden.

Apps

  • Cisco Secure Client (Android, iOS, Windows, macOS): Verbindung hinzufügen, Server {{ info.oc_addr }}.{% if not info.le %} Da der Server ein eigenes Zertifikat nutzt, in den App-Einstellungen „Nicht vertrauenswürdige Server blockieren“ deaktivieren oder das CA-Zertifikat installieren.{% endif %}
  • OpenConnect (Linux, NetworkManager-Plugin network-manager-openconnect): VPN-Protokoll „Cisco AnyConnect“, Gateway {{ info.oc_addr }}.
  • Kommandozeile: sudo openconnect {% if not info.le %}--servercert {{ info.pin }} {% endif %}-u {{ c.name }} {{ info.oc_addr }}
  • Windows/macOS ohne Cisco: OpenConnect-GUI bzw. „openconnect“ per Homebrew.
