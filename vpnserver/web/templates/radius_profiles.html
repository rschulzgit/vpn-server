Profile für RADIUS-Benutzer

← RADIUS-Einstellungen

Diese Profile enthalten keine Zugangsdaten: Jeder Benutzer meldet sich mit seinem Benutzernamen und Passwort des RADIUS-Servers an. Das VLAN weist der RADIUS-Server zu. Die Dateien können an alle Benutzer verteilt werden.

{% if not state.radius.enabled %}
Es ist noch kein externer RADIUS-Server aktiviert. Lokale Clients können diese Profile ebenfalls verwenden (mit Client-Name und Passwort).
