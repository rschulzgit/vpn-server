Kein Zugriff von außen? Häufige Ursachen
  • DS-Lite / CGNAT: Viele Kabel- und Glasfaseranschlüsse haben keine eigene öffentliche IPv4-Adresse. Portfreigaben für IPv4 sind dann nicht möglich. Lösung: beim Provider eine öffentliche IPv4 (bzw. „Dual-Stack“) anfragen.
  • Test aus dem eigenen WLAN: Viele Router unterstützen kein „NAT-Loopback“. Testen Sie über das Mobilfunknetz (WLAN am Handy aus).
  • Falsche Adresse: Die öffentliche Adresse (oben) muss auf Ihre aktuelle öffentliche IP zeigen.
  • Doppel-NAT: Hängt Ihr Router hinter einem weiteren Router/Modem, müssen die Ports auf beiden weitergeleitet werden.
